Dossier Display (300, opsz 24–60, Latin) and Dossier Text (400 with opsz 8–32; static 600; static italic 400) are subsets of Source Serif 4, renamed because "Source" is a Reserved Font Name; licence in OFL.txt.
Source: npm `source-serif@4.5.1` (Adobe), files `VAR/SourceSerif4Variable-Roman.ttf` and `VAR/SourceSerif4Variable-Italic.ttf`.
Made with fontTools 4.68 (`pyftsubset`-equivalent subsetting, then `varLib.instancer` to pin wght and limit opsz), name table renamed, superior ⁺ ⁻ (absent upstream) drawn from the font's own superior en dash, saved as woff2; unicode ranges are in fonts.css.
